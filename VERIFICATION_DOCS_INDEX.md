## 🎯 Start Here

### **Your Question:**
> "How admin can add verification documents with essential description to g2b?"

### **Quick Answer:**
Admin uploads documents during Phase 1 review with type, description, and file URL. Officer sees documents with descriptions in Phase 2 and verifies against government records.
