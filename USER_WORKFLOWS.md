## 👤 BUYER WORKFLOWS

### Workflow 1: Browse & Search Listings

**Step 1: Landing Page Experience**
- Open malazone.com
- View dynamic carousel showcasing 5 business zones:
  - Property (መሬትና ቤት)
  - Motors (መኪናና ኤሌክትሪክ)
  - Stay (አዳራሽና ጌስት ሃውስ)
  - Ceremony (ልብስና ዲጄ ኪራይ)
  - Heavy Machinery (ከባድ ማሽነሪዎች)

**Step 2: Use Search Widget**
- Select Zone (Property, Motors, Stay, Ceremony, Heavy)
- Select Location (Hawassa Tabor, Lakefront, Piassa, Yirgalem, etc.)
- Select Intention (Buy, Rent, Hourly)
- Click "Search" or use quick-toggle pills

**Step 3: Browse Results Grid**
- View responsive grid of listing cards
- Each card shows:
  - Feature photo with badges (Verified, 0 KM, Premium, etc.)
  - Price in ETB
  - Key specs (bedrooms, fuel type, capacity, etc.)
  - Direct contact buttons

**Step 4: Filter & Sort**
- Filter by category tabs
- Filter by location dropdown
- Sort by: Newest, Price ↑, Price ↓
- Click "Load More" for pagination

**Step 5: View Listing Details**
- Click any listing card
- View full details page with:
  - All images (WebP optimized)
  - Complete specifications
  - Seller information
  - View count tracking

## 💼 SELLER WORKFLOWS

### Workflow 1: Create New Listing

**Step 1: Prepare Listing Information**
- Gather asset details:
  - Title (in Amharic & English)
  - Description (in Amharic & English)
  - Price and pricing model (fixed, per day, per month, per hour)
  - Location (Hawassa area)
  - Contact phone (Ethiopian format: 09XXXXXXXX or +2519XXXXXXXX)

**Step 2: Prepare Images**
- Take high-quality photos (up to 8 images)
- Each image max 5MB
- Supported formats: JPG, PNG
- System auto-converts to WebP (60-70% smaller)

**Step 3: Access Listing Creation**
- Navigate to "List Asset" section
- Fill in required fields:
  - Title (Amharic & English)
  - Category selection
  - Price and pricing suffix
  - Location selection
  - Phone number
  - WhatsApp number (optional)

**Step 4: Add Category-Specific Details**

**For Property:**
- Number of bedrooms
- Number of bathrooms
- Area in square meters
- Title deed type (Carta, Village, etc.)
- Furnished status

**For Motors:**
- Plate code and region
- Fuel type (Benzine, Diesel, Electric, Hybrid)
- Condition (New, Invoiced, Used)
- Mileage (KM)
- Manufacture year
- Transmission type

**For Stay/Halls:**
- Capacity (number of guests)
- Amenities (JSON array)
- Minimum rental days

**For Heavy Machinery:**
- Machinery brand
- Machinery type
- Capacity in tons
- With operator option

**Step 5: Upload Images**
- Select up to 8 images
- System processes automatically:
  - Resizes to max 1200px width
  - Converts to WebP format
  - Compresses to 80% quality
  - Saves with unique UUID filename

**Step 6: Submit Listing**
- Click "Submit Listing"
- System validates all fields
- Auto-creates user account if phone number is new
- Listing becomes active immediately
- Receives unique listing ID

**Step 7: Verification (Optional)**
- Admin can verify listing with "Carta Verified" badge
- Admin can mark as "Premium" for featured placement
- Verification increases trust and visibility

## 🎯 MALA-AGENT WORKFLOWS

### Workflow 1: Agent Registration

**Step 1: Eligibility Check**
- Must be Hawassa resident
- Youth or university student preferred
- No upfront costs required
- Can earn up to 1,000 ETB/day

**Step 2: Access Registration**
- Scroll to "Mala-Agents Banner" section
- Click "Join as Mala-Agent" button
- Fill registration form:
  - Full name (minimum 3 characters)
  - Phone number (Ethiopian format)
  - Sub-city (Tabor, Lakefront, Piassa, etc.)

**Step 3: Submit Registration**
- System validates phone format
- Checks for duplicate registrations
- Auto-creates user account if new
- Creates agent profile with "active" status

**Step 4: Receive Confirmation**
- Success message in Amharic & English
- Checkmark animation
- Ready to start listing properties
